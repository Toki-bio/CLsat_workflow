# CLsat consensuses

- `CLsat1.cons.fa` ... `CLsat4.cons.fa`: the four family consensuses (config `families.*.consensus`).
- `CLsat_sub_subfamilies.anchored.fa`: the nine sub-subfamily consensuses (CLsat1.1-1.5, CLsat2, CLsat3.1-3.2, CLsat4),
  in the common frame starting at the CLsat1 motif AAAGAAG. This is the file the final Darevskia run used as
  `subfamily.consensuses` (run_gb_v2 manifest sha256 849d4dc34f3eb924a97ac2214c90b6b2197b1d7605430a4ca67cffd67f850d36;
  on the run server it was named fig1b_rotated.fasta).
